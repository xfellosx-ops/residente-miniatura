# El Residente Miniatura
Juego educativo para el examen del Consejo Mexicano de Nefrología. Niveles disponibles: 9-5 Nefritis lúpica y 9-6 Vasculitis ANCA y anti-MBG.

    npm install
    python3 build.py levels/9-6-anca   # genera dist/index.html y dist/9-6.html (ábrelo en el navegador)
    npm test                           # juega todos los niveles de forma automática

Guía de trabajo: `CLAUDE.md`. Diseño y pendientes: `docs/DISENO.md`.
