# El Residente Miniatura
Juego educativo para el examen del Consejo Mexicano de Nefrología. Juego completo: mapa de 9 regiones, 32 niveles (los 26 temas; el 9 en 7 subniveles) y la Torre del Consejo de 300 preguntas.

    npm install
    python3 build.py                   # genera dist/index.html con todo el juego (ábrelo en el navegador)
    npm test                           # juega todos los niveles de forma automática

Guía de trabajo: `CLAUDE.md`. Diseño y pendientes: `docs/DISENO.md`.
