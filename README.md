# El Residente Miniatura
Juego educativo para el examen del Consejo Mexicano de Nefrología. Nivel disponible: 9-5 Nefritis lúpica.

    npm install
    python3 build.py          # genera dist/index.html (ábrelo en el navegador)
    npm test                  # juega el nivel completo de forma automática

Guía de trabajo: `CLAUDE.md`. Diseño y pendientes: `docs/DISENO.md`.
